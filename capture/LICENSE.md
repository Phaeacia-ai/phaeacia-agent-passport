WHY THIS CHANGED

Until the project was archived this directory was proprietary, all rights
reserved. When Agent Passport was published as open source and archived, the
browser capture prompt was relicensed to match the capture skill, which had been
relicensed the same way on 2026-08-18: it is the browser-side half of the same
capture, and an archived project with one closed half cannot be forked whole.
