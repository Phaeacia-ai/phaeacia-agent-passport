## `capture/`, relicensed on archiving

Until the project was archived, `capture/` was proprietary, all rights reserved.
It is now CC BY 4.0 like the capture skill, so the project can be forked whole.

kind is granted for them: not the Apache License 2.0, not CC BY 4.0, not for

## Your passports

Nothing here claims any interest in a passport you produce with these tools, in
the agent it describes, or in anything either of them outputs. An assembled
passport carries two components of this project inside section 5: the installer
text (CC BY 4.0) and the judge prompt (Apache 2.0). Each asks only what its own
licence asks of whoever redistributes it.
