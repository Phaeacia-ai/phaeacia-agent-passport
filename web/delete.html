Delete a passport.

Deletion is immediate and irreversible. There is no undo and no archive. Afterwards the link behaves exactly like a link that never existed, which is deliberate: a visitor must not be able to tell a deleted passport from an invented one.

Paste the whole link. The part that matters is taken out of it.

If you no longer have it, the passport cannot be deleted. It was never stored in a form anyone can read back, including us.

This form accepts 20 attempts an hour from one network, right or wrong, counted in fixed hours rather than a sliding one, which is the only thing stopping somebody flooding it. Past that it stops answering for the rest of the hour and then starts again on its own. Nothing about your passport or your token changes while it is waiting.

Deleted

The passport is gone. Its link now returns the same page as a link that never existed. Anyone who already read it still has what they read, which no delete button anywhere can change.
